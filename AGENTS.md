# TraceLens

TraceLens is a local-first Firefox privacy analyzer.

## Core Rules
- 100% local analysis
- No backend
- No telemetry
- Never upload browsing history
- Never upload URLs
- Never send cookies externally
- No cloud-based analysis

## Goal
Detect:
- Trackers
- Ads
- Analytics
- Third-party requests
- Cookies
- Permissions

Generate a clear privacy report and privacy score.
